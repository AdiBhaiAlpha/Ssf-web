== Description ==

Borbila PhotoCard Generator adds configurable PhotoCard tools to supported post and product editors. Version 2.0 introduces a redesigned, responsive administration dashboard and Borbila license protection.

When the license is inactive:

* All PhotoCard settings remain read-only.
* Direct settings submissions are rejected safely.
* Post and product PhotoCard tools stay unavailable.
* Frontend PhotoCard download buttons are disabled.

License template ID: `photocard`
